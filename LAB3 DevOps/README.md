# Лабораторная работа 3 - CI/CD Best Practices

## Описание
Демонстрация основных плохих и хороших практик написания CI/CD пайплайнов на примере GitHub Actions.


---

## Сравнительная таблица практик

| № | Аспект | Bad Practice | Good Practice | Почему это важно |
|---|--------|--------------|---------------|------------------|
| 1 | **Версия actions** | `actions/checkout@v1` | `actions/checkout@v4` | Старая версия не поддерживается, содержит уязвимости и баги |
| 2 | **Установка Node.js** | `apt-get install nodejs npm` | `actions/setup-node@v3` | apt-get медленный (1-2 мин), action быстрый (5-10 сек) |
| 3 | **Таймаут job** | Отсутствует | `timeout-minutes: 10` | Без таймаута зависший процесс может работать до 6 часов |
| 4 | **Триггер запуска** | `on: [push]` | `on: push: branches: [main]` | Запуск на всех ветках расходует CI/CD ресурсы впустую |
| 5 | **Версия Ubuntu** | `ubuntu-latest` | `ubuntu-22.04` | latest может измениться и сломать совместимость |
| 6 | **Таймаут команд** | `sleep 5` | `timeout 10 bash -c 'sleep 5'` | Защита от зависания отдельных команд |

## История про Васю

**Основные выводы:**
- Показывает абсурдность погони за технологиями ради технологий
- Важно понимать "зачем", а не просто "как" использовать инструменты
- DevOps - это культура и подход, а не просто набор инструментов
- Критикует избыточную сложность современной инфраструктуры

В контексте этой лабораторной: важно не просто знать синтаксис GitHub Actions, а понимать зачем нужны best practices и как они влияют на качество разработки.

## Выводы

Правильное написание CI/CD пайплайнов важно для:

- **Стабильности**: использование фиксированных версий предотвращает неожиданные поломки
- **Производительности**: правильный выбор инструментов экономит время сборки
- **Экономии ресурсов**: таймауты и условные запуски сокращают расход CI/CD минут
- **Предсказуемости**: контроль версий ОС и зависимостей обеспечивает воспроизводимость

Даже простые улучшения, показанные в этой работе, могут значительно повысить эффективность CI/CD процессов.
